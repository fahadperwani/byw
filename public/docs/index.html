API docs by Redocly

BYW API (1.0.0)

Download OpenAPI specification:

OpenAPI documentation for custom endpoints in the BYW (Strapi v5) backend. Standard Strapi CRUD endpoints also exist for most content-types under /api/{collection}. This spec focuses on business flows and custom routes (auth, payment, wedding, predefined-task, task-template).
